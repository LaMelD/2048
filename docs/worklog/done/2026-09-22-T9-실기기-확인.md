# 2026-09-22 — T9 실기기 확인

## 실측 환경

```
기기      SM-F766N (Galaxy Z Flip7), Android 16, SDK 36
해상도    1080x2520, density 480 (override 420)
디스플레이 2개 (커버+메인) — screencap -p 를 stdout으로 받으면 경고가 섞여 PNG가 깨진다
```

## 실행한 것

```
python3 (Pillow 12.3.0)  → assets/ 아이콘 5장 생성, 1024×1024, 2048 타일 모티프
npx expo prebuild --platform android --no-install   → android/ 생성, build.gradle 패키지명 2줄
./gradlew assembleDebug   → 1m 48s, app-debug.apk 130M   (기기 없이 의존성 캐시 목적)
./gradlew assembleRelease → 1m 24s, app-release.apk 65M  (debug 키 서명, JS 내장)
adb install -r app-release.apk → Success
adb shell am start -W    → LaunchState COLD, TotalTime 252ms
```

## 결정

- **실기기 확인은 release APK로.** debug APK는 Metro 번들러를 계속 띄워야 해 세션 관리가
  번거롭고, release는 JS가 내장돼 독립 실행된다. 계획은 `expo run:android --device`(debug)였으나
  바꿨다. T10에서 어차피 release를 재확인하므로 확인 횟수도 준다.
- 아이콘은 Pillow로 코드 생성. 디자인 도구 없이 1024 캔버스에 둥근 타일(#edc22e) + 흰 "2048".

## 함정

- **`adb exec-out screencap -p > x.png`는 Z Flip7에서 깨진다.** 디스플레이 2개 경고가 stdout에
  섞인다. `screencap -p /sdcard/x.png` 후 `adb pull`로 우회.
- **Claude Code Bash 셸의 adb 서버는 USB를 못 본다.** `system_profiler SPUSBDataType`도 빈 출력.
  사용자 터미널에서 `adb devices`로 서버를 띄우면 Claude의 adb 클라이언트가 localhost:5037로
  그 서버에 붙어 기기를 본다. **Claude 쪽에서 `adb kill-server`를 하면 다시 끊긴다.**
- `pm list packages`가 `user 150` 권한 에러를 낸다 — 삼성 보안 폴더. `--user 0`로 지정하면 조용.
- gradle이 "Deprecated features, incompatible with Gradle 10" 경고 — Expo 57 템플릿 문제, 무시.

# 2026-09-22 — 버그 수정·사용성 개선 (T11~T13)

## 왜 하는가

T9 실기기 검증 후 사용자가 보고한 2건. Linear 마일스톤 "버그 수정·사용성 개선" 신설.

1. 보드 밖에서 스와이프하면 인식 안 됨
2. 병합 시 애니메이션 없이 숫자만 바뀜

## 원인 (코드 읽고 확정)

1. `Board.tsx`가 `PanResponder`를 보드 View에만 붙임. 보드 밖 터치는 아무도 안 받음.
2. `slideLine`이 병합된 뒤쪽 타일을 결과에서 빼서 즉시 언마운트. 앞쪽 타일은 값이 즉시 바뀌고 팝만.

## 결정

- `swipe-hook-on-content-view`: 스와이프 감지를 `useSwipe` 훅으로 빼서 App의 content View(화면 전체)에 붙인다. 헤더 버튼 위 드래그는 Pressable이 먼저 잡음 — 의도.
- `ghost-tiles-for-merge`: 원작 2048 방식. `slide`가 사라진 타일에 목표 좌표를 줘 `ghosts`로 반환. Board가 tiles보다 먼저 렌더(아래). 같은 `key`라 기존 컴포넌트가 spring 이동. App이 150ms 뒤 비움. Tile은 값 변화를 120ms 미뤄 표시 후 팝.
- `GameState.ghosts?`는 옵셔널. `save`가 tiles/score/nextId만 쓰므로 저장에서 자동 제외. 기존 테스트 33건 무수정.
